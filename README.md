#**Novio Online Writing App - Frontend Project**
An online writing web app designed to read and write stories in various genres, and publish own stories. 

##Live Demo 
https://novio-writing-app-mcmb.vercel.app/ 

##Features included in MVP version 
-User Authentication (sign up/ log in/ log out) 
-Follow & Unfollow users (authors) 
-Like chapters of published stories 
-Write comments on the published chapters 
-Customize chapter & story (Adding images, chapter number, tags, genre, ...) 
-Editing profile (Add profile picture, Add bio, ...) 
-Guest User Homepage
-Responsive desgin 
-Loading & Error states 
-Designed 404 page 
-Delete Account 
-Publish, Unpublish stories, chapters 
-Notification 

##Tech Stack 
-**Frontend:** Next.js (App Router), React, Tailwind CSS, Flowbite, Sonner
-**BAAS:** Supabase 
-**Auth & Database:** Supabase Auth, PostgreSQL 
-**Deployment:** Vercel
