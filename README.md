# Novio Online Writing App – Frontend Project

An online writing web app designed for reading and writing stories in various genres, and publishing original stories.

##  Live Demo
https://novio-writing-app-mcmb.vercel.app/

##  Features included in MVP version
- User authentication (sign up / log in / log out)
- Follow & unfollow users (authors)
- Like chapters of published stories
- Write comments on published chapters
- Customize chapters & stories (add images, chapter number, tags, genre, etc.)
- Edit profile (profile picture, bio, etc.)
- Guest user homepage
- Responsive design
- Loading & error states
- Custom 404 page
- Delete account
- Publish & unpublish stories and chapters
- Notifications

##  Tech Stack
- **Frontend:** Next.js (App Router), React, Tailwind CSS, Flowbite, Sonner
- **BaaS:** Supabase
- **Auth & Database:** Supabase Auth, PostgreSQL
- **Deployment:** Vercel
